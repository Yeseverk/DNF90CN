只有三步。照做就行，不用装任何东西。


【第一步】解压到一个新文件夹
────────────────────────────────────────────────────

把这个 ZIP 解压到一个空文件夹，比如：

    D:\DNF90CN

注意三点：

  · 不要解压到桌面，不要解压到 C 盘的"程序文件"里
  · 不要解压到中文路径或带空格的路径
  · 如果你以前解压过旧版本，请换一个新文件夹，
    不要覆盖旧的


【第二步】替换客户端的五个文件
────────────────────────────────────────────────────

找到你的 DNF 客户端文件夹（里面有 DNF.exe 的那个）。

把本包 client-patch\bin\ 里的这两个文件复制进去，覆盖同名文件：

    90CN.dll
    90CNLua.dll

客户端文件夹里必须有这五个文件才能玩：

    DNF.exe（或 NoPack.exe）
    90CN.dll
    90CNLua.dll
    ijl15.dll
    ijl15_real.dll

后面两个是客户端自带的，一般不用动。


【第三步】双击 LOGIN.bat
────────────────────────────────────────────────────

双击本文件夹里的：

    LOGIN.bat

会闪一下黑框，然后弹出「DNF90CN 登录器」窗口。

在窗口里：

  1. 点「选择客户端」，选到你客户端文件夹里的 DNF.exe
  2. 填账号和密码（自己想一个，不是官方账号）
  3. 第一次用点「注册并进入」
     以后用点「进入游戏」

剩下的全自动，等它把游戏拉起来就行。

以后每次玩，只要双击 LOGIN.bat。

  出问题了怎么办
════════════════════════════════════════════════════

【黑框里写"这个文件夹不是完整的游戏包"】

  你下载的是 GitHub 源码，不是游戏包。
  源码里没有游戏程序、没有数据库、没有游戏资源，
  怎么弄都跑不起来。

  解决：找发包的人要完整发布包（几百 MB 的 ZIP）。
  文件夹名字带 -main 的，一律是源码，不能玩。


【黑框里写"这个目录里的服务端是旧版本"】

  你的包太旧了，跟当前版本对不上。

  解决：找发包的人要最新的包，解压到新文件夹。


【登录器里提示"客户端文件版本不匹配"】

  五个文件里至少有一个不对，最常见是 90CN.dll 没换，
  或者换成了自己编译的版本。

  解决：重新做一遍第二步，一定要用本包 client-patch\bin\
  里的那两个 DLL，不要用别处来的。


【第一次启动特别慢】

  正常。第一次要解压并初始化数据库，可能要等一两分钟。
  第二次开始就快了。


【游戏卡住了 / 打完副本出不来】

  这是已知问题，正在修。

  请帮忙做一件事：把下面两个地方的文件发给开发者，
  这对定位问题非常有用：

    本文件夹\runtime\logs\  里最新的 server-*.log
    你的客户端文件夹\90CN_trace.log

  另外说清楚：当时在做什么操作、卡在哪一步。


════════════════════════════════════════════════════
  其他文件是干什么的（一般用不到）
════════════════════════════════════════════════════

  LOGIN.bat     正常入口，就用这个
  STATUS.bat    看服务端状态、端口、账号绑定
  STOP.bat      停止服务端（不删数据）
  START.bat     只启动服务端，不开登录器

平时只用 LOGIN.bat 就够了。
